# Contributing

Contributions that improve firmware reliability, radio configuration, hardware documentation, or reproducibility are welcome.

## Guidelines

- Document the exact board/module and pin mapping for hardware changes.
- Keep radio-related behavior within applicable local regulations and test only on equipment you are authorized to use.
- Do not commit credentials, private keys, tokens, or device-specific secrets.
- Include reproduction steps for build, display, input, or RF configuration issues.
- Update documentation when dependencies or supported hardware change.

Pull requests should explain what changed, why, and how it was validated.
